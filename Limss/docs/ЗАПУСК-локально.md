# ЛИМС ГМЗ-5 — локальный запуск

## Требования
- **PHP 8.1+** (проверить: `php -v`)
- **Node.js 18+** и npm (`node -v`)
- **Composer** (менеджер пакетов PHP). Если не установлен — есть `composer.phar` в папке `C:\Claud code\LIMS\`.
- База: локально используется **SQLite** (сервер БД не нужен). Продакшн-цель — MSSQL/MySQL.

## Быстрый старт (Windows, двойным кликом)
1. **`setup.bat`** — один раз: ставит зависимости, настраивает `.env` (SQLite), создаёт и наполняет БД, собирает фронтенд.
2. **`run.bat`** — запуск сервера. Открыть в браузере: **http://127.0.0.1:8000**
3. Вход: **логин `zzzz1111*` / пароль `zzzz1111*`**

Для разработки (Vite HMR): **`dev.bat`**.

## Ручной запуск (по шагам)
```bat
php ..\composer.phar install        REM или: composer install
npm install
copy .env.example .env
REM в .env: DB_CONNECTION=sqlite, DB_DATABASE="<абсолютный путь>/database/database.sqlite"
php artisan key:generate
type nul > database\database.sqlite
php artisan migrate --seed --force
npm run build
php artisan serve --host=127.0.0.1 --port=8000
```

## Полезное
- Пересобрать фронтенд после правок: `npm run build` (или держать `npm run dev`).
- Пересоздать БД начисто: `php artisan migrate:fresh --seed --force`.
- Собранные ассеты (`public/build`) в git не хранятся — собираются командой `npm run build`.

## Доступ для заказчиков (демо)
Чтобы заказчики открыли приложение у себя в браузере, вводили данные и проверяли.

### 1) В той же сети (офис / Wi-Fi)
1. Запустить `run.bat` (сервер слушает `0.0.0.0:8000`).
2. Один раз открыть порт в брандмауэре — терминал **от администратора**:
   ```
   netsh advfirewall firewall add rule name="LIMS 8000" dir=in action=allow protocol=TCP localport=8000
   ```
3. Дать заказчикам ссылку `http://<IP-этого-ПК>:8000` (IP показывает `run.bat`, напр. `http://192.168.1.26:8000`).

### 2) Через интернет (удалённо)
1. Запустить `run.bat` (сервер).
2. Запустить `tunnel.bat` — появится публичная ссылка `https://XXXX.trycloudflare.com`, её отправить заказчикам.
   - Ссылка меняется при каждом запуске туннеля. Для постоянной ссылки нужен аккаунт Cloudflare (named tunnel).
   - `cloudflared.exe` лежит в `C:\Claud code\LIMS\`.

**Примечание:** `php artisan serve` обрабатывает запросы по одному — годится для демо на несколько человек. Для реальной эксплуатации/нагрузки позже развернём полноценный веб-сервер (Nginx/Apache + PHP-FPM) и БД MSSQL.

## Настройка под завод (тираж)
Формат шифров/номеров — в `config/lims.php` и через `.env`:
```
LIMS_SAMPLE_PREFIX=TL      # префикс шифра пробы
LIMS_SAMPLE_FORMAT={prefix}-{year}-{month}-{seq}
LIMS_CERT_PREFIX=PS        # префикс номера паспорта
```
