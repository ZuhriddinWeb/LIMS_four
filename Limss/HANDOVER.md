# LIMS ГМЗ-5 — передача проекта

ЛИМС (лабораторная информационная система) 5-го гидрометаллургического завода НГМК.
Laravel 10 (PHP 8.3) + Vue 3 SPA. Цель — тиражирование на 8 гидрометзаводов комбината.

## Стек
- **Backend:** Laravel 10, PHP 8.3, Sanctum (токен-авторизация)
- **БД:** SQLite (локально) → **MSSQL** (продакшн-цель). Кросс-движковые bit/tinyint обрабатываются как `Number(x) === 1`.
- **Frontend:** Vue 3 SPA, Vuestic UI 1.9.12, vue-router, vuex, vue-i18n (legacy:false), ag-Grid, chart.js, xlsx (SheetJS)
- **Сборка:** Vite (`npm run build`)

## Что в архиве
Включено: весь исходный код, миграции, готовый `.env` (SQLite, портируемый — путь к БД по умолчанию
`database/database.sqlite`), рабочая БД с демо-данными `database/database.sqlite`, история git (`.git`).
**Не включено** (регенерируется установкой): `node_modules`, `vendor`, собранные ассеты `public/build`.

## Запуск с нуля
```bash
composer install
npm install
npm run build                 # собрать фронтенд (или для разработки: npm run dev)
# .env уже вложен (SQLite, ключ приложения задан). БД с демо-данными уже на месте.
# Если нужна чистая БД:  php artisan migrate:fresh --seed
php artisan serve --host=0.0.0.0 --port=8000
```
Открыть http://localhost:8000 . Пользователь для входа уже заведён в демо-БД.
Если `.env` по какой-то причине отсутствует: `cp .env.example .env`, выставить `DB_CONNECTION=sqlite`,
оставить `DB_DATABASE` пустым (тогда используется `database/database.sqlite`), затем `php artisan key:generate`.

## Архитектура (ключевое)
- **Лабораторный блок** (`resources/js/pages/lab/`, `components/LabComponent/`, `app/Http/Controllers/api/Lab*`):
  пробы с уникальным шифром → маршрутизация группа-заказчик → группа-исполнитель → ввод результатов по
  показателям → статусы → паспорта качества/протоколы. ВЛК с картами Шухарта (`/lab/qc`), оборудование
  (статусы/поверка/ТО/файлы), ИИ-помощник трендов воды/воздуха (`/lab/ai`), дашборд (`/`).
- **Дизайн-система:** `resources/js/lims-ui.css` — тема-адаптивные классы (`.lims-page/.lims-panel/.lims-table/
  .chip/.lims-btn/...`), переменные под `:root` (светлая) и `html.dark-theme` (тёмная). Тема по умолчанию — тёмная,
  переключатель в навбаре, хранится в `localStorage.theme`.
- **Трёхязычность (RU/UZ/EN):** composable `resources/js/composables/useLang.js` → `L(ru, uz, en)` для UI-меток
  (реактивно), `isRu`/`nameOf` для полей данных (в БД только `Name`/`NameRus`, EN→RU fallback). Ключи vue-i18n —
  в `resources/js/locale.js` (полные блоки ru/uz/en). Локаль в `localStorage.locale`.
- **Справочники** конфиг-driven: `referenceConfigs.js` + generic `LabReferencePage.vue`.

## Текущее состояние
Полностью готов и отревьюен в браузере (обе темы, 3 языка): дашборд, журнал проб (шифры, маршрутизация),
ввод результатов → протокол, ВЛК (карта Шухарта: центр/±2σ/±3σ), паспорта качества (сквозная прослеживаемость
проба→результаты→паспорт), оборудование, ИИ-тренды. Весь лабораторный блок — премиум-UI + трёхязычный.

### Реализовано (пакет «Целостность данных / ISO 17025»)
- **Аудит-трейл** (`lab_audit_log`, трейт `App\Models\Concerns\Auditable`, сервис `App\Support\LabAudit`):
  автоматически пишет created/updated/deleted/restored с разницей полей (old→new), пользователь (через
  guard `sanctum`), IP. Все 19 моделей лаборатории — с `SoftDeletes` (жёсткого удаления нет).
  Просмотр: страница `/lab/audit` + API `GET /lab/audit`, `/lab/audit/meta`, `/lab/audit/{type}/{id}`.
- **Утверждение результатов + эл. подпись** (ISO 17025 §7.8): `lab_sample_determinations.ResultStatus`
  = entered → reviewed → approved; поля Reviewed/Approved By/At. Эндпоинты: `POST /lab/determinations/{id}/review`,
  `/approve` (нужна предв. проверка), `/reopen` (с причиной, аудируется). Утверждённый результат заблокирован
  от правки (423). Статус пробы автоматически повышается до `approved`, когда все определения утверждены.
- **Авторизация API**: все маршруты `/lab/*` (кроме скачивания файла) в группе `auth:sanctum`; неавторизованный
  запрос → 401. Во фронте axios-интерцептор при 401 очищает токен и уводит на вход.
- **Центр оповещений** `/lab/alerts` + колокольчик в навбаре со счётчиком: ожидают проверки/утверждения,
  поверка приборов, ВЛК вне допуска, просроченные пробы (TAT). Пороги — `config/lims.php`.
- **Метрология методик** (`lab_methods`): LOD/LOQ, расширенная неопределённость (U, %), знаки округления —
  редактируются в справочнике методик, показываются в карточке пробы и в протоколе/COA.

### Реализовано (тираж и безопасность)
- **Пер-заводская конфигурация/брендинг** — `config/lims.php['plant']` (name/company/lab/city/logo/аккредитация),
  всё через env (`LIMS_PLANT_*`, `LIMS_COMPANY_*`, `LIMS_ACCRED_*`). Инъекция во фронт: `window.__LIMS__`
  (blade), композабл `usePlant()`. На новом заводе меняется только `.env`, код не трогается.
- **Права на бэкенде (RBAC)** — middleware `perm:<роль>[,<действие>]` (`App\Http\Middleware\LabPermission`,
  алиас `perm` в `Kernel.php`) на всех маршрутах лаборатории; действие по HTTP-методу или явное; нет прав → 403.
- **PDF-паспорт качества (COA)** — кнопка в списке паспортов формирует печатную форму A4 с шапкой завода,
  реквизитами, таблицей показателей (значение/ед./норма НД/методика/соответствие), вердиктом и блоками подписей;
  сохраняется как PDF через печать браузера. Генерация: `printCert` в `LabCertificatesPage.vue`.

## Открытые задачи (требуют решения владельца)

2. **Серверная генерация PDF** (опц.) — сейчас COA печатается из браузера (Save as PDF). При желании — dompdf/snappy
   для генерации файла на сервере (потребует composer-зависимость).
3. **Интерфейс приборов / импорт результатов из файла** (CSV/Excel) — ускоряет ввод.
4. **Несоответствия и корректирующие действия (CAPA)** — ISO 17025 §7.10/§8.7.
