```bash
composer install && npm install
php artisan migrate      # 4 новые миграции (см. ниже)

```
**Важно:** API теперь требует авторизации и прав. Демо-БД вложена, пользователь заведён.

(первый пользователь имеет все права).

## Доработки

### 1. Целостность данных (ISO 17025)
- **Аудит-трейл** — авто-запись «кто/что/когда + старое→новое» по всем изменениям.
  Новое: `app/Support/LabAudit.php`, `app/Models/Concerns/Auditable.php`, `app/Models/LabAuditLog.php`,
  `app/Http/Controllers/api/LabAuditController.php`, страница `resources/js/pages/lab/LabAuditPage.vue`.
  Эндпоинты: `GET /lab/audit`, `/lab/audit/meta`, `/lab/audit/{type}/{id}`.
- **Мягкое удаление** — трейт `SoftDeletes` на всех моделях `Lab*` (жёсткого удаления нет).
- **Утверждение результатов + эл. подпись** — цикл `entered→reviewed→approved`, блок после утверждения (423),
  переоткрытие с причиной. Логика в `LabSamplesController` (методы `review/approve/reopen`), UI —
  `LabSampleCard.vue`. Эндпоинты `POST /lab/determinations/{id}/review|approve|reopen`.

### 2. Безопасность
- **Авторизация API** — все `/lab/*` (кроме скачивания файла) в группе `auth:sanctum`; axios-интерцептор на 401
  в `resources/js/app.js`.
- **RBAC на бэкенде** — middleware `perm:<роль>[,<действие>]` (`app/Http/Middleware/LabPermission.php`,
  алиас `perm` в `app/Http/Kernel.php`) на всех маршрутах лаборатории. Нет права → 403.

### 3. Метрология и вывод
- **LOD/LOQ, неопределённость (U, %), округление** на методиках (`lab_methods`), редактируются в справочнике,
  показываются в карточке пробы и в протоколе.
- **PDF-паспорт качества (COA)** — кнопка в списке паспортов формирует печатную форму A4 (шапка завода,
  реквизиты, показатели, вердикт, подписи) → Save as PDF. Генерация: `printCert` в `LabCertificatesPage.vue`.

### 4. Оповещения и дашборд
- **Центр оповещений** `/lab/alerts` + колокольчик в шапке (`LabAlertsController`, `LabAlertsPage.vue`,
  правки `Sidebar.vue`): ожидают утверждения, поверка приборов, ВЛК вне допуска, просроченные пробы (TAT).
- **Дашборд** — KPI «Ожидают утверждения» + лента «Недавняя активность» (события аудита).
- **История записи** в карточке пробы (кнопка «История», `GET /lab/samples/{id}/history`).

### 5. Тираж на 8 заводов
- **Пер-заводская конфигурация/брендинг** — `config/lims.php['plant']` (всё через `.env`: `LIMS_PLANT_*`,
  `LIMS_COMPANY_*`, `LIMS_ACCRED_*`). Инъекция во фронт: `window.__LIMS__` (blade) → композабл
  `resources/js/composables/usePlant.js`. **На новом заводе меняется только `.env`.**

### 6. Соответствие ТЗ по объекту испытания (раздел 2) и оборудованию (1.5)
Добавлены недостающие по ТЗ поля/функции:
- **2.3** партия/серия пробы (`lab_samples.Batch`).
- **2.4** описание + химический состав (`Description`, `ChemicalComposition`).
- **2.7** условия хранения и транспортировки (`StorageConditions`, `TransportConditions`).
- **2.8** сопроводительные документы — загрузка файлов к пробе (`lab_sample_files`,
  `POST /lab/samples/{id}/file`, скачивание `/lab/sample-file/{id}/download`).
- **2.11** место хранения как **динамический справочник** (`lab_storage_locations` + страница
  «Места хранения» `/lab/storage`, роль `menu.lab_storage`), поле `StorageLocationID` + уточнение.
- **2.12** срок хранения (`StorageUntil`) + оповещение об истечении (центр оповещений).
- **2.14** оформление утилизации (`POST /lab/samples/{id}/dispose`: акт/дата/кто/причина, аудируется).
- **1.5** заблаговременное напоминание по оборудованию: `CalibrationDueSoon`/`DaysToVerification` →
  жёлтая пометка «через N дн.» в списке приборов (а не только «просрочено»).

Все новые поля видны в форме регистрации пробы и в карточке пробы; 4 миграции `2026_09_17_*`.

## Обновление 19.09.2026 — Технологический контроль (сменные журналы)
Добавлен модуль лабораторного техконтроля по сменам (флотация/сорбция/обжиг/десорбция) — как
**лабораторные результаты** (не дискретные пробы с шифром).
- Миграции: `..._create_lab_process_measurements_table` (точка×показатель×дата/смена/время×значение,
  SoftDeletes+Auditable), `..._add_process_role` (роль `menu.lab_process`, выдана пользователям с правом на пробы).
- `app/Models/LabProcessMeasurement.php`, `app/Http/Controllers/api/LabProcessController.php`
  (index по точке+дате, `bulkSave` сетки, `journal` — суточные средние за месяц, destroy).
- Страница `resources/js/pages/lab/LabProcessPage.vue` (`/lab/process`): точка+дата+смена, показатели
  столбцами, строки-время, среднее по столбцу, сохранение. Пункт меню + локали (ru/uz/en).
- Эндпоинты под `auth:sanctum` + `perm:menu.lab_process`.
- Точки берутся из справочника «Точки отбора» (`/lab/points`), показатели — из «Показателей» (`/lab/analytes`).
