
В ЦНИЛ имеются 4 лаборатории.
1.Технологическая лаборатория по золоту.
1,1. Группа по гравитации
1,2. Группа по цианировании
2.Геологическая лаборатория.
3.Аналитическая лаборатория. 
3,1. Спектральная группа
3,2. Химическая 
3,1. Спектральная лаборатория
3,2. Химическая лаборатория
4.Лаборатория по решению водных проблем.

ПО должно включать в себя следующие функциональные возможности:

Базовые возможности.
1.Управление оборудованием:
1.В какой лаборатории или службе относится оборудование
1.1. Учет приборов и их калибровки или поверки;
1.2.Планирование технического обслуживания.
1.3.Ведение базы данных всего лабораторного оборудования (название, модель, серийный номер, местоположение, поставщик, дата ввода в эксплуатацию).
1.4.История изменений, ремонтов, замен компонентов.
1.5.Напоминания о предстоящих проверках (по дате, количеству использований или другим условиям).
1.6.Статусы оборудования: рабочее, на обслуживании, вне эксплуатации, ожидает калибровки и т.д.
1.7. Блокировка использования оборудования, не прошедшего калибровку или обслуживание.
1.8. Фиксация, на каком оборудовании проводились конкретные испытания.
1.9.Хранение сертификатов калибровки, актов обслуживания, инструкций по эксплуатации.
2. Объекты испытание (Автоматизация регистрации и отслеживания проб):
2.1. Уникальный номер (идентификатор) объекта.
2.2. Тип объекта: сырьё, продукция, вода, воздух, биоматериал, и т.д.
2.3. Название, код, партия или серия
2.4. Описание объекта (физические характеристики, химический состав).
2.5. Источник или поставщик объекта.
2.6. Дата поступления.
2.7. Условия хранения и транспортировки.
2.8. Сопроводительные документы (накладные, акты приёмки).
2.9. Статус объекта испытания(Новый / В процессе испытания / Испытан / Брак / Утилизирован.)
2.10. Назначение видов испытаний в зависимости от категории объекта.
2.11. Регистрация мест хранения объекта (например, холодильник, сейф, полка №...).
2.12. Отслеживание сроков хранения.
2.13. Отчет по пробам
2.14. Оформление процедуры утилизации объекта после завершения испытаний.
 
Принципиальная схема передвижения проб от получение до выхода результатов.
Технологическая лаборатория по золоту (ТЛ) один из группы (группы надо отдельно Группа по гравитации.Группа по цианировании) получает пробу от подразделений или с карьеров и т.д обрабатывает и дает уникальный номер(шифр) регистрирует с установкой;
- номер документа или местонахождение откуда получена проба (подразделении)
-номер пробы
- дата регистрации(автоматический при регистрации)
- кому передается (Спектральная группе или Химическая группе)
-с установкой определяемых элементов (в одном пробе может определятся один или несколько элементов)
-какая пробы жидкий или твёрдый
-какая группа заказчик (Группа по гравитации, Группа по цианировании, Геологическая лаборатория) 
-нужно разделить по  месяцам чтобы ввод было не все в месте а отдельно по месяцам
2. Аналитическая лаборатория получает пробу.

- группы видят отправленную пробу для своей группы и берут на работу для определение результатов по тем элементом которые включали заказчики.
-после выхода результатов заполняют данные по каждым элементом отдельно которые заказаны.
- установка времени и даты выхода результатов (автоматический)
- поиск пробы по дате или по номеру пробы
-архив данных
Лаборатория по решению водных проблем.
- номер документа или местонахождение откуда получена заказ (подразделении)
- в какую группу распределена работа (группа водных ресурсов, группа по воздоху, группа радиационного контроля)
-время или даты регистрации заказа
-какие определение 
-ввод результатов 
-даты результатов
-архив данных
-ИИ помощник для проведение анализов по времени о ухудшению или что в норме определенных сбора данных той или и ной местонахождений воздуха или источника воды.
